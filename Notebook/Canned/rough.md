# Roughing Cycles

### G71 - FANUC

- Roughing cycle that can be used on OD and ID turning.


```gcode

(G71 EXAMPLE)

(--------------------------)

G99G0X2.0Z.5M6 
X1.315Z.1

G71U(DEPTH OF CUT)R.01
G71P110Q120U.01(MAT TO LEAVE IN X)W.01(MAT TO LEAVE IN Z)F.016(ROUGH FEEDRATE)

(PROFILE G71 WILL FOLLOW)
N110G0X1.78W0.0
G1Z-.118F.008(FINISH FEEDRATE)  
X1.7W-.04
Z-.875
N120G1X1.315W-.05

(--------------------------)

(FINISHING)

G99G0X2.0Z.5M6 
X1.315Z.1(NORMAL SETUP CODE)

G70P110Q120

(--------------------------)

P=NUMBER START
Q=NUMBER FINISH

(SHOULD MATCH SEQUENCE NUMBERS INSIDE G71)


(--------------------------)



```

### G74 - HAAS

- Rough OD Turn Cycle    
  - Can also be used as peck drilling operation    
 
X = X FINISHED DIAMETER    
Z = Z FINISHED DEPTH    
I = X INCREMENT BETWEEN PECK CYCLES    
K = Z PECK DISTANCE    

```gcode

(G74 EXAMPLE)

N1 T101 (WNMG - FACE - R TURN) 
G50 S1800 
G96 S600 M03 
/ M08 
G00 G99 G54 Z0.3 
X3.8 Z0.01 
G01 X1.8 F0.004 
G00 X3.76 Z0.1 (X AND Z START POSITION)

G74 X3.26 Z-2.38 I0.05 K0.2 F0.008

(TURNS DOWN .5" USING A .2" PECK IN THE Z AND EACH PASS IS .05" IN X)

G00 X6. Z6. M09 
G97 S400 M03 
G00 G28 U0 
M01

(G74 EXAMPLE TWO)

N9 T909 (CCMT3251 - HTM15 INSERT) 
(ROUGH .72 HOLE) 
G50 S1800 
G96 S800 M03 
G00 G54 Z0.2 
/ M08 
X0.51 
Z-1. 
G74 X0.71 Z-1.748 I0.025 K0.05 F0.008 
G00 Z2. M09 
G00 G28 U0. M05 
M01 

```

### G75 - HAAS

- Rough facing cycle    

X = X POS FACE OFF TO    
Z = Z POS FACE OFF TO    
I = DOC X PECK CYCLE - IF LEFT OUT CYCLE WILL MAKE SINGLE PASS TO X POSITION    
K = DOC Z EACH PASS    

```gcode

(G75 EXAMPLE)

(--------------------------)

N1103 T1111 (CCGT32.5 - ALUM INSERT .008" CR) 
G00 G28 U0 
G50 S500 (FACE) 
G96 S526 M03 
G00 G99 G54 Z0.25 (START Z POSITION)
G00 X12.2 (START X POSITION)

G75 X9.4 Z0.05 K0.1 F0.006 (I VALUE LEFT OUT - SINGLE PASS TO X9.4)

G00 X12.2 W0.02 
Z0. 
G01 X9.4 F0.006 
G00 X12.5 Z0.5 
G00 G28 U0 M09 
G00 G53 Z-6. 
M05 
M01

```
