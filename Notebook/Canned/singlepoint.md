# Single Point Threading Cycles


## G76 - Two line format single point thread cycle    

`G76 P030555 Q003 R.003`      
`G76 X1.205 Z-.635 P0735 Q0280 F.0833`      

### Structure:    


`P` - **Three Parts:**      

**03** = 3 finishing passes    
**05** = Number of threads to pull out - in this case it pulls out after only a half thread    
**55** = Angle of threads (Usually 60 deg - using 55 can help with tool wear somehow)    

`Q` - Depth of first cut
